# 豆柴ショート「新しいベッドで寝床づくり」

YouTubeショート用（縦 1080×1920 / 60fps / 13.5秒）の編集素材一式です。

## ファイル

| ファイル | 内容 |
|---|---|
| `shiba_short_premiere.xml` | **Premiere Pro用シーケンス**（Final Cut Pro XML形式） |
| `shiba_short_preview.mp4` | テロップ入り完成見本（このままアップロードも可） |
| `captions/telop_1_top.srt` ほか | **編集できるテロップ**（上・中央・下の3トラック分のキャプションファイル） |
| `media/shiba_bed_vertical_master.mp4` | 元動画の画角全体を縦型に収めた素材（上下黒帯・HDR→SDR変換・音量+14dB） |
| `media/endcard_freeze.png` | ラストの静止画（空っぽのベッド） |
| `media/telop/*.png` | テロップ画像（透過PNG・1080×1920） |
| `fonts/MPLUSRounded1c-ExtraBold.ttf` | テロップで使ったフォント（M PLUS Rounded 1c / SIL OFL） |
| `tools/` | テロップ画像・キャプション・XML・見本動画を再生成するスクリプト |

## Premiere Proでの開き方

1. `dog-short` フォルダごとPCにダウンロードする（フォルダ構成は変えない）
2. Premiere Pro →「ファイル」→「読み込み」→ `shiba_short_premiere.xml` を選択
3. 「メディアをリンク」画面が出たら `media/shiba_bed_vertical_master.mp4` を指定 → 残りは自動でリンクされます
4. シーケンス「豆柴ショート_新しいベッドで寝床づくり」を開く

## テロップを編集できるようにする

XMLに入っているテロップ（V2・V3）は画像なので文字を変えられません。
文字を自由に直したいときは、`captions/` のキャプションに置き換えます。

### 1. キャプションを読み込む
1. 「ファイル」→「読み込み」で `captions/` の3ファイルを読み込む
2. 3つをそれぞれタイムラインの先頭（00:00:00:00）にドラッグ → キャプショントラックが3本できます
   - 「キャプションの形式」を聞かれたら **サブタイトル** を選択
3. V2・V3（画像のテロップ）は目のアイコンでオフにするか削除

| ファイル | 置き場所 | 内容 |
|---|---|---|
| `telop_1_top.srt` | 上の黒帯 | 豆柴パピーの日常 → 寝床づくりの結果 |
| `telop_2_center.srt` | 映像の中央 | 放置ｗ（ラストのみ） |
| `telop_3_bottom.srt` | 下の黒帯 | 本編テロップ7つ |

### 2. 見た目を整える（エッセンシャルグラフィックス）
キャプショントラックのクリップを選び、「ウィンドウ」→「エッセンシャルグラフィックス」で設定します。
1つ設定したら「トラックスタイル」→「スタイルを作成」で保存すると、同じトラックの全テロップに反映されます。

フォントは `fonts/MPLUSRounded1c-ExtraBold.ttf` をPCにインストールしてからPremiereを起動してください。

| 項目 | 上（telop_1_top） | 中央（telop_2_center） | 下（telop_3_bottom） |
|---|---|---|---|
| フォント | M PLUS Rounded 1c ExtraBold | 同左 | 同左 |
| サイズ（目安） | 54 | 150 | 84〜100 |
| 塗り | こげ茶 `#5C3414` | オレンジ `#EE8430` | 白 `#FFFFFF` |
| 境界線 | なし | こげ茶 `#5C3414`・20 | こげ茶 `#5C3414`・14 |
| 背景 | クリーム `#FFF8E8`・角丸 | なし | なし |
| 位置（領域） | 上中央 | 中央 | 下中央 |
| 縦位置の目安 | 上から約500px | 約960px | 約1380px〜 |

ショートでは画面の下約20%と右端がボタンやタイトルで隠れるので、下のテロップは1600pxより上に収めてください。

### 3. 細かい調整
- 文字を直す：プログラムモニターでテロップをダブルクリックして入力、または「テキスト」パネルの「キャプション」タブで編集
- 表示時間を変える：キャプションクリップの端をドラッグ
- 一部だけ色やサイズを変える：その文字だけ選択して設定（例：「お？」をオレンジ・大きめ、「※寝る前の〜」を小さめ 46程度）
- もっと自由にレイアウトしたい場合：キャプションを右クリック →「キャプションをグラフィックにアップグレード」で通常のテキストレイヤーになります

## 仕上げのおすすめ

- **BGM**：元の音はほぼ環境音だけなので、YouTubeの「オーディオライブラリ」やショートの楽曲追加機能で、ポップで軽い曲を付けるのがおすすめ（元音は -10dB 程度に下げる）
- **効果音**：「お？」(9.6秒)に「ポン」、脱走(10.6秒)に「シュッ」、「放置ｗ」(11.5秒)に「チーン」などを入れるとテンポが良くなります
- 元動画の画角を切らずに見せるため上下は黒帯です。ヘッダーは上の黒帯、テロップは下の黒帯（ショートのUIに隠れない高さ）に配置しています
